# Vértice CRM

Mini-CRM para los vendedores de **Vértice Labs** (Marcelo, Martín y Luciano):
clientes, estados, envío de mails y flyers de venta, todo en un solo lugar.

## 🔗 Link

👉 **https://lucianog13.github.io/crm-verticelabs/**

## 🔑 Contraseña

`vertice2026` (compartida, para los tres).

## Cómo se usa

1. Abrí el link.
2. Escribí la contraseña y tocá **Entrar**.
3. Tocá tu nombre (Marcelo / Martín / Luciano).
4. Ahí ves tus clientes, los marcás con ✅ ⏳ ❌ y mandás mails.
5. Abajo tenés el **Material de venta** con los flyers para mandar por WhatsApp.

---

**Stack:** frontend estático (vanilla JS) en GitHub Pages · Supabase (datos y login) · Brevo (mails).
